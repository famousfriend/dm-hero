# Reference Codex data

`srd-5.1.json` is generated by `scripts/build-codex-srd.mjs` from the SRD 5.1 JSON
files of the `dnd5-srd` npm package (v1.0.0, github.com/soryy708/5e-database, MIT).
It holds only System Reference Document 5.1 content: 15 conditions, 319 spells, 325 monsters.

This work includes material taken from the System Reference Document 5.1 ("SRD 5.1")
by Wizards of the Coast LLC and available at
https://dnd.wizards.com/resources/systems-reference-document. The SRD 5.1 is licensed
under the Creative Commons Attribution 4.0 International License available at
https://creativecommons.org/licenses/by/4.0/legalcode.

Do not add content from other books here. Non-SRD material is link-only (5e.tools URL)
or imported locally by the user, never bundled.
