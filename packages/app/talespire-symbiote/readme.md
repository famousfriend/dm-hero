# DM Command Center

Shows the fight that is running in DM Command Center (DM Hero) on this computer: turn order, HP, AC and conditions, with buttons that put a monster's attack dice in your dice tray. The results are written into the fight's action log in the app, and can be posted to the TaleSpire chat.

DM Command Center has to be open on the same computer. Install or update this panel from the app: Settings, TaleSpire, "Install the panel in TaleSpire".
